# Synchronization protocol additions - Services

Supported entity types added:

- `service_category`
- `service`
- `service_price`
- `service_order`
- `service_order_item`
- `service_staff_assignment`
- `service_payment`
- `service_expense`
- `service_revenue_allocation`
- `staff_earning_transaction`
- `staff_settlement`

Processors should validate device credentials, business and branch ownership, module availability, idempotency and immutable completed transactions.
