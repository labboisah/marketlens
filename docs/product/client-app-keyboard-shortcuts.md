# Client App Keyboard Shortcuts

This document defines MarketLens Client App keyboard shortcuts for desktop POS workflows.

## POS Shortcuts

- F2: Focus product search.
- F4: Focus customer search.
- F6: Open payment dialog.
- F8: Hold current sale draft, or resume held sale when cart is empty.
- F9: Complete sale from payment dialog, or open payment dialog when not open.
- Esc: Close payment dialog.

## Notes

- Shortcuts are active on the POS screen.
- Financial completion remains blocked while disconnected.
- Sale completion remains blocked when a pending idempotent sale requires status confirmation.
- Held sale uses workstation session storage only, not an independent transaction database.

## Accessibility

- Shortcut hints are displayed on the POS screen in English-first labels.
- Hausa localization foundation is available for the shortcut labels.
