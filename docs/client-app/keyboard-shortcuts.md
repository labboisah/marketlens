# Client App Keyboard Shortcuts

This document lists implemented keyboard shortcuts in the POS workflow.

## POS Shortcuts

- F2: Focus product search.
- F4: Focus customer search.
- F6: Open payment dialog.
- F8: Hold current sale draft, or resume held sale when cart is empty.
- F9: Complete sale from payment dialog, or open payment dialog when not open.
- Esc: Close payment dialog.

## Usability Notes

- Shortcuts are visible from the in-app helper panel.
- Focus indicators are explicit for keyboard users.
- Reduced motion mode is respected via CSS media query.

## Accessibility

- Use keyboard-first navigation where barcode scanners emulate key input.
- Keep controls reachable with clear labels and semantic ordering.
- Ensure workflows remain operable without color-only cues.

## Localization Foundation

- English is default language.
- Hausa translation keys exist as foundation and can be expanded.
